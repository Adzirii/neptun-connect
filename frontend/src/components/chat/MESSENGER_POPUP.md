# Messenger Popup Component

Компонент всплывающего окна чата в стиле Facebook Messenger для Neptun Connect.

## Описание

MessengerPopup - это компонент, который создает плавающую кнопку чата в правом нижнем углу экрана. При нажатии открывается модальное окно с полным функционалом чата.

## Функции

### 1. **Плавающая кнопка (Floating Button)**
- Располагается в правом нижнем углу экрана
- Показывает количество непрочитанных сообщений
- Анимация при наведении (увеличение)
- Скрывается при открытии окна чата

### 2. **Модальное окно чата**
- Размер: 380px ширина, 600px высота
- Возможность минимизации/максимизации
- Закрывается по клику на overlay или кнопку закрытия
- Плавная анимация появления/исчезновения

### 3. **Фоновое изображение**
- При открытии окна показывается фоновое изображение (pasted_image_3.svg)
- Затемненный overlay для лучшей видимости окна
- Клик по overlay закрывает окно

### 4. **Полный функционал чата**
- Список всех разговоров
- Отправка сообщений
- Прикрепление файлов
- Ответ на сообщения
- Редактирование и удаление сообщений
- Навигация между списком чатов и конкретным чатом

## Использование

### Базовое использование

```tsx
import { MessengerButton } from './components/chat/MessengerPopup';

function App() {
  return (
    <>
      {/* Ваш основной контент */}
      <div>...</div>
      
      {/* Кнопка Messenger */}
      <MessengerButton />
    </>
  );
}
```

### Интеграция с контекстами

Компонент автоматически интегрируется с существующими контекстами:
- `AuthContext` - для получения текущего пользователя
- `ConversationContext` - для управления разговорами
- `MessageContext` - для работы с сообщениями

## Компоненты

### MessengerButton

Плавающая кнопка с индикатором непрочитанных сообщений.

**Props:** Нет

**Состояние:**
- `isOpen` - состояние открытия/закрытия popup окна
- `unreadCount` - общее количество непрочитанных сообщений

### MessengerPopup

Всплывающее окно с чатом.

**Props:**
```tsx
interface MessengerPopupProps {
    isOpen: boolean;        // Состояние открытия окна
    onClose: () => void;    // Callback для закрытия окна
}
```

**Состояние:**
- `isMinimized` - минимизировано/максимизировано окно
- `showConversationList` - показывать список чатов или конкретный чат
- `replyingTo` - сообщение, на которое отвечаем

## Стилизация

### Цвета (Neptun Theme)

- **Хедер**: `#2C3E50` (темно-синий)
- **Кнопка**: `#3498DB` (синий)
- **Hover**: `#2980B9` (темно-синий)
- **Непрочитанные**: `#E74C3C` (красный)

### Размеры

- **Кнопка**: 56x56px (с padding 16px)
- **Окно**: 380x600px
- **Минимизировано**: 380x56px

### Анимации

- **Появление окна**: slide up + fade in (300ms)
- **Hover кнопки**: scale(1.1)
- **Transitions**: `transition-all duration-300`

## Фоновое изображение

Расположение: `/public/pasted_image_3.svg`

Изображение представляет собой SVG с градиентом в стиле Neptun:
- Градиент от `#2C3E50` до `#3498DB`
- Сетка для декоративного эффекта
- Логотип "N" в центре
- Декоративные круги

### Замена изображения

Чтобы заменить фоновое изображение:

1. Поместите новое изображение в `/public/`
2. Обновите путь в `MessengerPopup.tsx`:
   ```tsx
   backgroundImage: 'url(/ваше_изображение.png)'
   ```

## Особенности реализации

### Управление состоянием

- Использует локальное состояние для UI (`isOpen`, `isMinimized`)
- Подключается к глобальным контекстам для данных
- Автоматически пересчитывает непрочитанные сообщения

### Responsive поведение

- Фиксированная ширина 380px (оптимально для мобильного просмотра)
- Адаптивная высота (600px или 56px при минимизации)
- Z-index: 50 (выше большинства элементов)

### Производительность

- Lazy loading компонентов чата
- Условный рендеринг (не рендерится пока не открыто)
- Оптимизированные transitions

## Взаимодействие с пользователем

### Keyboard shortcuts

Можно добавить:
```tsx
// ESC для закрытия
useEffect(() => {
  const handleEsc = (e: KeyboardEvent) => {
    if (e.key === 'Escape') onClose();
  };
  window.addEventListener('keydown', handleEsc);
  return () => window.removeEventListener('keydown', handleEsc);
}, [onClose]);
```

### Drag & Drop

Окно можно сделать перемещаемым, добавив библиотеку типа `react-draggable`.

## Troubleshooting

### Проблема: Кнопка не видна

**Решение:** Проверьте z-index других элементов на странице.

### Проблема: Фоновое изображение не загружается

**Решение:** 
1. Проверьте путь к файлу в `/public/`
2. Убедитесь, что файл называется `pasted_image_3.svg`
3. Проверьте консоль браузера на ошибки 404

### Проблема: Анимация дергается

**Решение:** Добавьте `will-change: transform` в CSS или используйте GPU-acceleration.
